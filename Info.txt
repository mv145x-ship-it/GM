Данные — общий файл, с данными за все года с 2000 по 2024 и всеми дамми-переменными.
Данные 2014 все — сокращённый файл общих данных по 2014 год, который использовала для расчёта базовой модели.
Данные для прогноза 2014, 2025 — файл в котором рассчитывали, возможные значения 2024 года по базовой модели и на 2025 по последней модели.
Экспорт импорт по группам стран и товаров — данные с ФТС, по которым графики рисовали.
