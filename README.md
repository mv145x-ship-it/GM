# Гравитационная модель российской внешней торговли в условиях санкций

Репозиторий содержит данные, код и рукопись научной статьи
**«Гравитация российской внешней торговли в условиях санкций: структурные оценки по панели 32 стран, 2000–2024 гг.»**.
Исходная идея — выпускная квалификационная работа (`ВКР.docx`, данные `Данные*.xlsx`, описание `Info.txt`);
в статье спецификация модели и методика заменены на структурную гравитацию (PPML, фиксированные
эффекты «страна — год» и «пара»), добавлены анализ динамики, гравитационный ориентир и проверки статистического вывода.

**Главное, что нужно знать о данных.** Ряды торговли — из набора ВКР (UN Comtrade, суммарная торговля пары, 2000–2024);
в среде, где проводилась работа, не было доступа к официальным источникам (World Bank API, IMF, UN Comtrade, CEPII, ФТС),
поэтому данные **не обновлялись до 2025 г. и не верифицировались по первичным источникам**. Аудит набора выявил дефекты
(см. ниже), которые учтены в анализе, но не устранены. Конвейер обновления данных готов (раздел «Обновление данных»),
проверен на тестовых примерах, но не запускался на реальных API.

## Воспроизведение

```bash
pip install -r requirements.txt            # + pandoc (для DOCX); gretl — по желанию
python code/04_main_models.py              # таблицы 1–4 и сводки (results/)
python code/05_event_study_counterfactual.py
python code/06_inference_checks.py --perm 500 --boot 200      # самый долгий шаг
python code/07_figures.py
python code/08_build_paper.py              # рукопись: paper/article_ru.md и article_ru.docx
```

Готовые `data/*.csv` и `results/*` лежат в репозитории, поэтому шаги 04–09 можно запускать без шага 01.
Шаг 01 (пересборка набора данных из `Данные.xlsx`) требует трёх открытых репозиториев:

```bash
git clone https://github.com/datasets/gdp        /home/user/datasets/gdp          # зеркало WDI: ВВП
git clone https://github.com/datasets/population /home/user/datasets/population   # зеркало WDI: население
git clone https://github.com/pachadotdev/cepiigeodist /home/user/pachadotdev/cepiigeodist   # CEPII GeoDist
python code/01_build_dataset.py --wb-dir /home/user/datasets --geodist /home/user/pachadotdev/cepiigeodist/data/dist_cepii.rda
```

Все числа в тексте и таблицах рукописи подставляются из `results/`; интерпретационные формулировки
(в `paper/parts/*.md`) при смене данных нужно перечитывать вручную.

**gretl.** В обоих скриптах `gretl/*.inp` укажите свой путь в строке `set workdir`; запуск:
`gretlcli -b /полный/путь/gretl/02_ppml_gravity.inp`. Скрипты используют годы 2000–2024 и 32 страны (при расширении панели правятся циклы).

## Данные и обозначения

* `trade` — суммарная торговля пары (экспорт + импорт), млн долл. США, текущие цены; `gdp_i`, `gdp_j` — ВВП, млрд долл.; `pop_*` — население, млн;
  `dist` — население-взвешенное расстояние CEPII (км); суффиксы `_i`, `_j` — страны пары (ориентация: `iso3_i < iso3_j`), `_ij` — парные переменные.
* Санкционные индикаторы **парные**: `sanc14_ij` = «Россия × ядро коалиции 2014 г.» × 1[t ≥ 2014]; `sanc22_ij` — то же для t ≥ 2022;
  отдельно — Республика Корея (`kor22_ij`) и Украина (`ukr14_ij`, `ukr22_ij`). Полный словарь — `data/DATA_DICTIONARY.md`.
* Дефекты исходных данных ВКР (отчёт — `data/data_quality_report.csv`, приложение А рукописи): «санкционные» дамми — чисто временные;
  расстояния у 89 пар расходятся с CEPII более чем на 10 %; ошибки в дамми БРИКС (2024) и НАТО (2000–2003); 29 значений торговли 2024 г. совпадают
  с 2023 г. (протянуты); аномальные скачки 2022 г. (ОАЭ и др.); ВВП на душу населения 2022–2024 гг. — другой источник.
  Часть из них (дамми, расстояния, ВВП) исправлена в `gravity_panel.csv`; протянутые значения помечены (`flag_carry`).

## Обновление данных (2025 г. и далее)

```bash
python code/fetch_update.py probe                       # какие хосты доступны
export COMTRADE_API_KEY=...                             # бесплатный ключ: comtradeplus.un.org
python code/fetch_update.py all --start 2000 --end 2025 # → data/raw_update/{wdi,weo,comtrade_directional}.csv
python code/10_merge_update.py --end-year 2025 --replace flagged   # → data/gravity_panel_updated.csv + update_report.csv
GM_PANEL=data/gravity_panel_updated.csv python code/04_main_models.py   # и далее 05–09
python tests/test_update_pipeline.py                    # тесты (на синтетических ответах, без сети)
```

Суммарная торговля пары строится как среднее двух зеркальных сообщений (экспорт + импорт, сообщённые каждой страной);
политика замены `--replace none|flagged|all` описана в `code/10_merge_update.py`. Хронология членства в `gravity_common.py`
уже учитывает вступление Индонезии в БРИКС (2025 г.). После обновления проверьте формулировки рукописи с годами «2022–2024»
и перечень ограничений (раздел 5.4).
